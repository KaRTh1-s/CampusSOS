# CampusSOS Frontend

## Status: PLANNED (To be initialized in Phase 2)

### Target Stack:
- **Framework**: React 18+ with TypeScript
- **Bundler**: Vite
- **Styling**: Modern Vanilla CSS Design System with accessible semantic HTML, responsive glassmorphic cards, clear status badges, and mobile-first ergonomics.
- **Routing**: Lightweight client-side navigation (Student Report Flow & Admin Dashboard).

### Key Planned Components:
- `ReportForm`: Natural language issue description input with length guards.
- `AIAnalysisCard`: Displays AI-derived category, priority, summary, and safety recommendations.
- `ConfirmationView`: Displays unique report ID and submission timestamp.
- `AdminDashboard`: Filterable incident management interface with status toggles (OPEN, IN_PROGRESS, RESOLVED).
